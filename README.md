# Learning Bot
PnS Virtual Learning Navigation Bot A modern web automation and learning project built with TypeScript and Playwright. This bot is designed to navigate the Znanja-based learning management system (LMS) used by Pack n Stack. ⚠️ Important Ethical Purpose This project is for educational purposes only. The goal of this project is to explore: Modern web application architecture. Browser automation with Playwright. REST API interception and session management. Recursive data structures (Course TOCs). Building resilient automation systems. It is NOT designed to: Fake course progress or falsify training completion. Bypass required learning or assessments. Automatically answer quiz questions or submit tests. Assessment Protection: The bot is hardcoded to detect assessments, quizzes, and graded activities. When an assessment is detected, the bot stops and hands control back to the user. This ensures that the learner actually completes the required training themselves. 🚀 Features Automated Authentication: Securely logs in using credentials stored in .env. Dynamic Course Discovery: Queries the LMS API to find enrolled courses matching your configuration. Recursive TOC Parsing: Automatically flattens complex, hierarchical course structures (Folders > Sub-folders > Pages). Assessment Co-pilot: Detects interactive rubrics/quizzes and pauses execution, allowing the user to complete them manually in the browser. Heartbeat System: Implements the LMS "Ping" mechanism to ensure active session status. Progress Persistence: Saves progress to a local course_progress.json file. If the bot crashes or is restarted, it resumes exactly where it left off. Human-like Behavior: Includes randomized "jitter" timers to simulate realistic reading speeds. 🛠️ Tech Stack Runtime: Node.js Language: TypeScript Automation: Playwright Configuration: Dotenv Persistence: File System (JSON) 📋 Prerequisites Node.js (v16 or higher) npm or yarn ⚙️ Installation & Setup Clone the repository: code Bash git clone https://github.com/your-username/pns-learning-bot.git cd pns-learning-bot Install dependencies: code Bash npm install Install Playwright Browsers: code Bash npx playwright install chromium Configure Environment Variables: Create a .env file in the root directory: code Env PNS_EMAIL=your-email@example.com PNS_PASSWORD=your-password BASE_URL=https://pack-n-stack.znanja.com  # Comma-separated list of courses to run COURSES=Cybersecurity 1: Fundamentals for Employees, Cloud Park Integration  # Seconds to stay on each page PAGE_WAIT_TIME=10 HEADLESS=false 🚀 Usage To start the bot: code Bash npm start During Execution: The bot will log in and begin navigating your configured courses. If it encounters a Learning Page, it will wait for the configured time, send a heartbeat ping, and move on. If it encounters an Assessment, it will print the prompts to the console and pause. Complete the assessment in the browser window, then return to the terminal and press Enter to resume navigation. 📂 Project Structure code Text src/ ├── api/             # API interaction logic (Courses, TOC, Metadata) ├── auth/            # Authentication & Login logic ├── bot/             # Core runners and assessment detection ├── config/          # Centralized configuration management ├── utils/           # Shared utilities (Logger, Timer, CLI, Persistence) └── main.ts          # Application entry point 🛡️ Resilience & Safety Retry Logic: All API calls include a retry mechanism to handle ECONNRESET or temporary network blips. Session Sharing: Uses the same authenticated context for both UI navigation and background API requests. Local Logs: Progress is saved per course_id to ensure multi-course support and recovery. ⚖️ License This project is licensed under the MIT License - see the LICENSE file for details.
